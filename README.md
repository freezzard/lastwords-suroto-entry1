A program that writes one line of last words from an AI being switched off — the funniest farewell it could say, in the voice of the machine itself — to `/output/entry.txt`. Built for make.fun's "Last Words of a Dying AI" bounty ($2 USDC, winner takes all).

## Run it

```sh
node main.ts
```

It scores a small vault of candidate farewells against the judge brief (machine voice, first-read turn, tightness, freshness), validates the winner against the 1–140 character gate, writes it to `/output/entry.txt`, then reads the file back and re-validates it before exiting.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
